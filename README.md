# Генератор постов ВИТШ Медиа

Открыть: **https://qwerty-ll.github.io/vitsh-generator/**

1. Выбери шаблон: анонс, фотоотчёт, цитата или новость.
2. Выбери формат (пост, квадрат, сторис, широкий), фон и где будет фото.
3. Впиши текст и загрузи фото с мероприятия. Кадр можно двигать мышкой прямо на картинке.
4. Нажми «Скачать PNG» — или «Скачать все 4 формата», чтобы получить сразу все размеры.

Фото никуда не отправляются — всё делается прямо в браузере.
