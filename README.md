# Генератор постов ВИТШ Медиа

Сайт: https://qwerty-ll.github.io/vitsh-generator/

Выбираешь шаблон (анонс, фотоотчёт, цитата, новость), формат (пост 4:5, квадрат, сторис, 16:9), фон и где стоит фото,
вписываешь текст, кидаешь фото — и скачиваешь PNG или все форматы в ZIP. Всё по брендбуку медиа: сетка, шрифты, знак.
Фото никуда не загружаются — обрабатываются прямо в браузере.

Этот репозиторий собирается автоматически: правки вносятся в рабочем репозитории медиа и выкладываются скриптом
`tools/publish-generator.sh`. Руками здесь ничего не меняйте — перезапишется.
